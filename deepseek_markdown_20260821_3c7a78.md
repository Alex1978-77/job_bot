# Job Search Bot

Телеграм-бот для автоматического поиска работы по всей России на основе вашего резюме.

### Возможности
- Поиск вакансий по всему интернету через Jooble API
- Фильтры: навыки, города, зарплата, удалёнка, исключение английского
- Ручной поиск через `/search`
- Автоматические уведомления каждый час
- Отметка откликов через `/apply`
- Импорт ранее откликнутых вакансий через `/import_applied`

### Установка и запуск
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` с переменными `BOT_TOKEN` и `JOOBLE_API_KEY`
3. Запустите: `python bot.py`

### Развёртывание на Render.com
Создайте Background Worker, укажите команды:
- Build: `pip install -r requirements.txt`
- Start: `python bot.py`
- Добавьте переменные окружения из `.env`

Все критерии поиска редактируются в `criteria.py`.
